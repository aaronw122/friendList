# friendList
made this bc i'm in a groupchat with some friends, and we send songs all the time to eachother. but, oftentimes i forget to listen. 

i believe songs are for listening, and memorabilia like this can bring people together, so i made this simple tool.

it runs locally on your machine, and scrapes any groupchats you choose to find spotify links, and adds them to a customized playlist.

completely private.
